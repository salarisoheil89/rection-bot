# ربات اشتراکی مدیریت ری‌اکشن کانال

نسخه پایه با Python، Aiogram 3 و PostgreSQL.

## نصب
1. فایل `.env.example` را به `.env` تغییر نام دهید.
2. توکن ربات را در `BOT_TOKEN` قرار دهید و رمز دیتابیس را تغییر دهید.
3. اجرا: `docker compose up -d --build`
4. گزارش اجرا: `docker compose logs -f bot`

برای اجرای محلی می‌توانید از `DATABASE_URL=sqlite+aiosqlite:///./bot.db` استفاده کنید.

## امکانات
- ذخیره Telegram ID، نام، نام خانوادگی، username، تاریخ عضویت و زبان.
- تست رایگان ۲۴ ساعته، فقط یک‌بار برای هر کاربر.
- هر کوین، فعال‌سازی یک کانال برای ۳۰ روز.
- افزودن کانال با بررسی مدیر بودن ربات.
- نمایش حساب، راهنما، تغییر زبان به ۹ زبان، درخواست شارژ و پشتیبانی.
- پنل مدیر، آمار، مشاهده کاربران، افزایش کوین، افزودن مدیر، تأیید درخواست شارژ و پیام همگانی.
- واکنش خودکار با یک واکنش از حساب ربات و گزارش در گروه متصل.

## اتصال گروه گزارش
کاربر باید گروه را خودش بسازد، ربات را اضافه کند و دستور `/connect TOKEN` را در گروه بفرستد. توکن بعد از افزودن کانال در پیام ربات نمایش داده می‌شود.

## محدودیت‌های تلگرام
ربات معمولی نمی‌تواند از طرف چند حساب، ۱۰ یا ۵۰ ری‌اکشن مستقل ثبت کند؛ Bot API فقط امکان ثبت واکنش حساب خود ربات را می‌دهد. همچنین ربات نمی‌تواند خودش گروه جدید ایجاد کند. در این نسخه، گروه موجود توسط کاربر متصل می‌شود. عدد ری‌اکشن دستی ۵۰ در متن راهنمای اولیه به‌عنوان محدودیت اجرایی پیاده نشده، چون با Bot API سازگار نیست.

## مدیران
نام‌های کاربری `Sikxven` و `B2nald` در اولین `/start` آن حساب‌ها به مدیر تبدیل می‌شوند. هر مدیر باید ابتدا ربات را باز کند و `/start` بزند. افزودن مدیر جدید: `/addadmin USER_ID`. افزایش موجودی: `/credit USER_ID COINS`.

پرداخت این نسخه به‌صورت درخواست شارژ و تأیید دستی مدیر است؛ درگاه بانکی هنوز به سرویس‌دهنده مشخصی متصل نشده است.
